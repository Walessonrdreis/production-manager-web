# Migração da Produção para Postgres (Prisma) - Passo 1

## Objetivo
Criar a base de dados em Postgres via Prisma para suportar a funcionalidade de "Controle de Produção", substituindo eventuais persistências difusas e preparando a integração mista (API Externa + API Interna).

## O que foi feito
- Adicionados os modelos `ProducedRecord` e `ProductionSchedule` em `apps/api/prisma/schema.prisma`.
- Realizado o push no banco de dados local via `npx prisma db push`.
- (TDD) Preparado o terreno para o Repositório de banco no backend.

## Próximos Passos
