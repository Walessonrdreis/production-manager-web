# Planejamento: Gestão de Estoque Baixo (Catalog V2)

**Status**: Em Planejamento
**Contexto**: Módulo de Controle V2 / API 1
**Data**: 2026-06-05

## Visão Geral
A tela de "Estoque Baixo" será o ponto central para garantir que a produção (Geração de Ordens de Produção) aconteça antes que os insumos e os produtos de venda quebrem o estoque. Ela atuará como a "Ponte" entre Vendas (Necessidade) e a Fábrica (Produção).

Para isso, o ERP (Omie) será nossa "Única Fonte de Verdade" para o Saldo Atual e a Definição de Estoque Mínimo (`minStock`). A plataforma irá consumir essas informações de forma reativa.

## Objetivos e Escopo
1. **Visualização Dinâmica de Faltas**: Listar apenas produtos ou insumos que estão com saldo menor ou igual ao seu Estoque Mínimo configurado.
2. **Setup Rápido via API 1 (Futuro ERP Update)**: Fornecer de forma rápida dentro da listagem (ex: modal ou popover no próprio card) uma ação para editar/definir rapidamente o "Estoque Mínimo" do produto, enviando um comando (update payload) para a API 1 (que fará a ponte do update na Omie).
3. **Conversão Rápida em Ordem de Produção (OP)**: Para produtos que estão em alerta e possuem "Estrutura (BOM)" atrelada, deverá existir um atalho que transporte o usuário diretamente para o fluxo de "Gerar OP".
4. **Base para Notificações (Próxima Fase)**: Ter essa listagem processada servirá de insumo vitalício para os Workloads / Jobs rodarem de tempos em tempos para enviar notificações via e-mail ou app apontando "Tem X produtos com estoque abaixo da cota ideal".

## Abordagem Arquitetural (Frontend)
- Utilização de `VITE_ENABLE_DEV_BOUNDARIES=true`/`DevBadge` para separar o que é dado do ERP (Saldo, Estoque Mínimo) e a ação local (Criar OP no APP).
- Reuso do Componente `CatalogV2List` injetando o hook customizado ou variação (`initialStockLevel="low"`) - que já temos a fundação feita.
- Criação de um Popover/Drawer simples no `ProductListCard` ou um botão "Editar Proteção/Estoque", que só faz uma mutação simples (`PATCH`) para a Carga de Trabalho da nossa API 1.

## UX (Experiência)
- O `Hub` do Catálogo já possui o Bloco "Estoque Baixo". Ao clicar nele, a sub-página exibe a listagem já filtrada.
- Os cards desses itens ficarão destacados (ex: borda laranja/vermelha dependendo da criticidade - saldo negativo, etc).
- As ações de card serão expandidas para: `[Ajustar Mínimo]`, `[Montar Carga / OP]`.

## Próximos Passos (Tech Steps)
1. **Backend (API 1):** Garantir ou mapear endpoint de update mínimo no Omie. (Isso está sendo fechado primeiro com os comandos CRUD do Omie).
2. **Frontend (V2):** Atualizar o Card `ProductListCard` para receber o formulário em linha (`Inline Form` via strategy `Fake/Real` com o gateway) de edição de "Estoque Minímo".
3. Ligar os Workloads (OP Criada com Lote Min / Prod).
