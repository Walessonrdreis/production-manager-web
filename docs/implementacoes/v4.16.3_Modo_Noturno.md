# Implementação do Tema Noturno (v4.16.3)

**Data:** 15/05/2026
**Responsável:** Agente GenAI

## Objetivo
Atendendo à requisição do usuário de "Adicionar modo noturno", foi integrado suporte completo para `Dark Mode` utilizando a implementação manual de estilos `.dark` através da estilização já fornecida pelo `TailwindCSS v4`. 

## Alterações Realizadas
1. **Ativação Global:**
   - Adicionado a declaração `@custom-variant dark (&:where(.dark, .dark *));` no arquivo `apps/web/src/styles/global.css` como o padrão do TailwindCSS v4 utilizado para ativar variações dark class-based.

2. **Contexto de Tema e Estado:**
   - Criado `ThemeContext.tsx` em `apps/web/src/contexts/ThemeContext.tsx` para gerenciar ativamente o estado de Tema localmente (`light` ou `dark`).
   - Sincronização e preferência de tema resgatada via `window.matchMedia('(prefers-color-scheme: dark)')` caso seja a primeira vez de utilização no cliente.

3. **Layout e Comutador (Toggle):**
   - Importando e atrelando o `ThemeProvider` de forma global dentro de `apps/web/src/app/App.tsx`.
   - Adicionado no `Topbar.tsx` o botão seletor dinâmico (Sun/Moon) para comutar localmente na aplicação o uso do modo noturno.

4. **Componentização Tailwind Dark Mode (Amostras):**
   - Aplicação de variações estruturais em `AppLayout.tsx`, `PageContainer.tsx` e `Card.tsx` que suportarão de forma perene fundos escuros do `bg-slate-900 / 950`.
   - Realizada a refatoração local (`refatoração local`) no Dashboard inteiro de forma ilustrativa provendo visibilidade e contraste as novas páginas.
   
## Como Expandir
Novos contâiners devem aplicar ativamente nas suas classes a variação "dark:" seguindo o construtor já embutido nas regras CSS e implementado aqui:
- Fundo básico: `bg-slate-50 dark:bg-slate-950`
- Contêiner de Dados: `bg-white dark:bg-slate-900`
- Textos Primários: `text-slate-900 dark:text-white`
- Subtextos Secundários: `text-slate-500 dark:text-slate-400`
- Linha divisória e bordas: `border-slate-200 dark:border-slate-800`
