# Implementação: Transição do Monitoramento da Etapa 20 para o Banco de Dados Local (v4.17.17)

## Problema / Objetivo
Os dados apresentados na página de Controle de Produção (Etapa 20) vinham defasados em relação à sincronização local. O algoritmo do `DashboardAdapter` continuava fazendo requisições ao serviço em nuvem antigo (na URL onrender.com) que não refletia as atualizações mais recentes contidas localmente pelo banco PostgreSQL (`prisma.order`).

## Solução Implementada
1. Refatoração do caso de uso `GetStage20TotalsUseCase` para acessar diretamente o `prisma.order`, consultando as ordens e extraindo o JSON para enviar à tela, garantindo estabilidade e fluidez.
2. Remoção do componente de integração antigo (`dashboard.adapter.ts`).
3. O endpoint interno do dashboard passa a fornecer o espelho exato da sincronização com segurança.
