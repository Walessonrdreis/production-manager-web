# Separação de Pedidos e Ordens de Produção (v4.21.0)

## Objetivo
Separar a atual página de Ordens (`/orders`), que mescla "Pedidos de Venda" (Omie) e "Ordens de Produção" (Locais) em abas, em duas páginas distintas e independentes no sistema. Isso melhora a clareza organizacional, resolve eventuais problemas de estado ao recarregar a página e adequa o menu lateral que agora está categorizado.

## Passos para Implementação

- [x] **Passo 1: Criar/Refatorar as Páginas Base**
  - Transformar a `OrdersPage.tsx` atual para focar estritamente em **Pedidos de Venda**, removendo a lógica de abas (Tabs).
  - Criar uma nova página `ProductionOrdersPage.tsx` dedicada exclusivamente à gestão de **Ordens de Produção**, aproveitando o componente que antes era uma aba.

- [x] **Passo 2: Atualizar o Roteamento**
  - No arquivo `Router.tsx`, manter a rota `/orders` (ou alterar para `/sales-orders`) para os Pedidos.
  - Adicionar a nova rota `/production-orders` apontando para a página recém-criada.

- [x] **Passo 3: Atualizar a Barra Lateral (Sidebar)**
  - No componente `Sidebar.tsx`, atualizar a categoria "Produção" para listar de forma clara:
    - **Pedidos** (apontando para `/orders`)
    - **Ordens de Produção** (apontando para `/production-orders`)
  - Ajustar os ícones para fazerem sentido em cada contexto (ex: ShoppingCart para pedidos, FileText/Clipboard para ordens).

- [x] **Passo 4: Validação**
  - Testar o recarregamento (refresh) em ambas as páginas isoladas para garantir que não ocorra perda de contexto da aba ou quebra da tela.
  - Garantir o funcionamento dos botões e listagens.

- [x] **Passo 5: Atualização da Documentação Central**
