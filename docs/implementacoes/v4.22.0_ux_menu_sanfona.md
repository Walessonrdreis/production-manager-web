# Melhoria de UX no Menu de Navegação (v4.22.0)

## Objetivo
Implementar uma melhoria na experiência do usuário (UX) do menu lateral (Sidebar). Ao clicar em um elemento filho (link de página), o sistema deve automaticamente retrair qualquer outra categoria (pai) que não seja a categoria do elemento clicado. Isso mantém o menu sempre limpo e reduz a carga visual (auto-collapse modal).
