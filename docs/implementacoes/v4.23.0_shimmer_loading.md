# Adição de Efeito Shimmer (Skeleton Loading) (v4.23.0)

## Objetivo
Implementar o padrão de *Skeleton Loading* com efeito *Shimmer* (onda de gradiente animado) no front-end. Esse efeito será exibido durante o carregamento assíncrono de dados para melhorar a percepção de performance e a experiência de usabilidade, entregando um UX moderno.

  - Checar as configurações do `tailwind.config.mjs` / CSS global para garantir suporte a custom animations se necessário, ou usar o `animate-pulse` nativo e modernizar.
  - Criar o componente central reutilizável `apps/web/src/components/ui/Skeleton.tsx`.
