# Implementação: Desligamento Transparente de API Externa (Omie) Mapeada por Variáveis de Ambiente
Versão: v4.23.1
Data: 20/05/2026

## 1. O Problema
A integração com o ERP legada da Omie estava temporariamente fora do ar. As requisições oriundas do Backend seguiam disparando, forçando a API Render local a cometer timeouts ou responder Arrays em branco e corromper persistências vitais através de deletes automáticos no Postgres.

## 2. A Solução
Adicionado um **Circuit Breaker** global no Request Interceptor da camada HTTP base da API do servidor node (`external.client.ts`). Implementamos o uso de uma flag de variável de ambiente (`DISABLE_EXTERNAL_SYNC`) para abortar instantaneamente e com segurança toda tentativa de comunicação se a API mestra for reconhecida como inoperante ou "em manutenção". 

## 3. Arquivos Modificados
- `apps/api/src/shared/integrations/external/external.client.ts`: Interceptor do Axios ajustado com verificação de ambiente `DISABLE_EXTERNAL_SYNC === 'true'`, configurado para retornar um `Promise.reject()` instanciando um Status 503 com mensagem informativa de timeout forçado.
- `.env.example`: Adicionada o protótipo visível e as instruções relativas à nova flag para guiar a configuração no Render.
- `PROJECT_SUMMARY.md`: Atualizado o CHANGELOG agregador da arquitetura técnica atestando a melhoria.

## 4. Impacto
Essa estratégia proativa não só conserva o fluxo assíncrono perfeitamente estável (Graceful Degradation), devolvendo visivamente respostas nulas ou arrays em branco no Frontend em vez do bloqueio trágico ou "tela branca", mas também protege estritamente a "Purga / Wipe" de registros locais obsoletos por parte de the `UseCases` (como o de deleção de itens do Primas por reflexo do array vazio exógeno não ser populado).

## 5. Como usar
No Painel do Render, o administrador deverá cadastrar e definir a System Environment Variable `DISABLE_EXTERNAL_SYNC` em seu projeto hospedado definindo em caso de parada a flag para a string literal `true` (Em lowercase). Caso o sistema de upstream volte a operação normal, pode-se suprimir a variável ou alterá-la para `false`.
