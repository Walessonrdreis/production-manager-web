# Implementação: Migração Stock — Fase 3 (Feature Flag e Fallback)

**Versão:** v4.24.3
**Data:** 2026-05-21
**Classificação:** Implementação Funcional / Implantação Contínua

## O que mudou
- **`STOCK_READ_SOURCE`:** Nova variável de ambiente documentada no `.env.example` para controle direcional do banco de dados (feature flag). Por padrão, iniciada como `legacy`.
- **`CoreProductStockRepository`:** Criação de um repositório provisório para realizar o _fetch_ e _mapping_ de dados do banco oficial (API 1), utilizando exclusivamente a instância oficial `prisma`.
- **`GetStocksUseCase` e `GetStockByIdUseCase`:** Implementadas lógicas de leitura condicional utilizando o valor de `STOCK_READ_SOURCE`.
  * Se `legacy`: A busca consome o repositório antigo.
  * Se `core`: A busca consome o repositório atual, convertendo o formato dos dados.
- **Graceful Fallback:** Foi implementado um bloco `try/catch` para que qualquer falha do `Core` dispare um aviso (WARN log) e retorne o payload mapeado do Legado garantindo que a visualização final do usuário não quebre.
- **Shadow Read Garantido:** O serviço paralelo de Shadow Read continua sendo acionado passivamente limitando logs agressivos e validando divergências reais de produção.
- **Write Control Limitado:** A gravação e o método `save` continuam intocados apontando somente para `PrismaStocksRepository` (Legado).

## Por que mudou
- Transição segura entre o sistema de dados da API 1 (novo) e da API 2 (legado). A mudança abrupta poderia acarretar downtime ou perdas de dados, mas utilizando _feature flags_ com _fallback_, garante-se _zero-downtime deployment_.
- Prepara o sistema e a interface para consumir dados provenientes do ERP, onde os produtos passarão a listar em quantidades ou negativados, o que é realidade.

## Como avaliar
A arquitetura neste momento pode ser manobrada utilizando a chave:
`STOCK_READ_SOURCE=core`

## Como desfazer (Rollback)
Basta retornar a variável de ambiente `STOCK_READ_SOURCE=legacy`. O comportamento permanecerá identicamente o anterior, acessando apenas o Legacy Cloud.
