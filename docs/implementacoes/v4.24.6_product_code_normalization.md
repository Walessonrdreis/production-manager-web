# Normalização de Product Code para Criação de Ordens (v4.24.6)

## Objetivo
Implementar a API 2 de Ordens de Produção (Create Production Order) para que aceite `productCode` do frontend, em vez de `productId` (que no lado da API 1 representa o ID no banco Omie `codigo_produto`). A API 2 atuará como fachada/isolamento: recebe o código humano, resolve o ID real interno e envia para a API 1 (preservada).

## Arquivos Criados/Afetados

1. **`apps/api/src/modules/production-orders/presentation/controllers/create-production-order.controller.ts`**:
   - Criado Controller que recebe, no payload (`req.body`), o campo legível `productCode`, junto com a quantidade e data da Ordem de Produção. Foi aplicada validação explícita no endpoint.

2. **`apps/api/src/modules/production-orders/application/use-cases/create-production-order.usecase.ts`**:
   - Criado o Use Case que instancia os repositórios para executar a consulta `findByCode` e assim resgatar o identificador interno `codigo_produto`. Após isso, aciona a camada de integração (`ProductionOrderIntegrationClient`) repassando este ID real (`omieProductId`) para o ambiente da API 1 de forma blindada e desacoplada.

3. **`apps/api/src/modules/production-orders/application/clients/production-order.integration-client.ts`**:
   - Extensão das interfaces, isolando contrato requerido pela API 1.

4. **`apps/api/src/modules/products/application/ports/product-read.repository.ts`**:
   - Criação da interface/Port para o Repositório de Leitura de Produtos que resolve código amigável para ID de sistema.

5. **`apps/api/src/modules/products/infrastructure/db/product-read.repository.prisma.ts`**:
   - Criado e implementado o Repositório local (Prisma) que busca `omieProduct` cruzando o `codigo` para devolver o `codigo_produto` mapeado para o Use Case.

## Comportamento Comprovado
- A API 1 (Legada ou Core de inserção) se manteve completamente blindada. Nenhuma alteração foi realizada na assinatura da API 1.
- O campo `productCode` entregue pelo curl/frontend entra na camada de apresentação da API 2.
- A consulta é efetuada no banco nativo garantindo o isolamento. O comando despachado para a camada Legada via Integração repassa com sucesso o ID Omie.
