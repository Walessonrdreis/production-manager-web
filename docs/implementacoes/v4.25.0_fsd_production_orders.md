# Implementação e Transição FSD: Ordens de Produção (v4.25.0)

## Planejamento Estratégico e Arquitetural (Atualizado)

Conforme as diretrizes (Regras 9, 13 e 14) e aprovação do usuário, a aplicação adotará uma variação do **Feature-Sliced Design (FSD)** focada em **alta coesão modular**. O módulo "Ordens de Produção" será autocontido dentro de `features/production-orders/`, operando como um "LEGO" independente que pode ser plugado ou removido sem quebrar a aplicação. 

O design baseia-se em um **Dashboard Modular (Hub)**, onde as subpáginas atuam como **Widgets/Cards Arrastáveis** na visão resumida e se expandem sob demanda.

### Estrutura Acordada para o Módulo
```text
src/
├── shared/                         # 🛠️ Nível 1: Design System Global
│   └── ui/ (Button, Input, Badge)
│
├── pages/                          # 🏢 Nível 2: Roteamento
│   └── production-orders-page/
│       └── ui/ProductionOrdersPage.tsx
│
└── features/                       # 🧩 Nível 3: Módulo Autocontido
    └── production-orders/
        ├── index.ts
        ├── subpages/               # Os blocos dinâmicos do Dashboard
        │   ├── OpenedOrders/
        │   ├── CreateOrder/
        │   ├── LiveOrders/
        │   ├── OrderReview/
        │   ├── OrderHistory/
        │   └── OrderMetrics/
        ├── components/             # Reuso interno de UI
        ├── model/                  # Gerenciamento de estado local (layout, grid)
        ├── api/                    # Integração com API (Monolito)
        └── ProductionOrdersHub.tsx # O Orquestrador (Grid Manager)
```
