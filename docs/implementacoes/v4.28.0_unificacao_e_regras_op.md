# Regras e Integração de Criação de OPs (FSD) - v4.28.0

## Contexto e Causa do Comportamento Atual (Criar OP que não aparece na fila)
Foi relatado que as OPs criadas no formulário não estão aparecendo na nova "Fila de Trabalho". 
Isso ocorre porque o código que cria a OP (`useProductionOrders`) pertence à estrutura legada (`features/production-order`), enquanto a "Fila de Trabalho / Opened Orders" foi recém-migrada para a subpágina FSD (`features/production-orders`). As duas implementações estavam utilizando *pontos de mock de memória* (arrays locais) distintos e disjuntos.

## Objetivo
Unificar o estado `Fake` de ordens de produção do domínio de OPs para FSD e implementar as novas regras condicionais impeditivas de domínio para a criação no Back-end Falso (como preparação para a virada de chave para a API real Relacional).

## Regras Impeditivas Solicitadas
1. **Estrutura (BOM) Inexistente:** O sistema identificará pelo produto Omie se o mesmo não possui estrutura técnica (BOM) cadastrada e rejeitará a solicitação.
2. **Insumo sem Preço de Custo:** Se o produto possui estrutura, o sistema fará a varredura e impedirá a abertura da OP caso qualquer insumo atrelado a ele esteja sem preço de custo referenciado no banco.
