# Implementação V4.28.11 - Hub do Catálogo V2 (Workloads Dashboard)

## Objetivo
Mudar a interface padrão do Catálogo V2 (lista corrida) para um Hub em formato de Dashboard, inspirado no funcionamento das Ordens de Produção (Kanban/Blocos Móveis). O objetivo principal é não sobrecarregar cognitivamente o usuário que abre a listagem do zero, permitindo que ele estabeleça suas prioridades de visualização organizando "Cards Interativos" (Dashboard de Acesso Rápido) customizáveis via drag-and-drop.

## Mudanças Realizadas
- **`useCatalogLayout.ts`:** Criado hook para estado do Hub, controlando a sub-página exposta e ordem de disposição dos blocos no Painel.
- **`CatalogV2Hub.tsx`:** O novo ponto de entrada root para o catálogo V2, orquestrando DndContext de blocos como botões para Listagem com filtros prefixados, similar ao modelo da OP V2.
- **Blocos Representacionais:** `AllProductsBlock.tsx`, `CreateProductBlock.tsx`, `LowStockBlock.tsx`, `WithBomBlock.tsx` — servindo de cards para demonstrar as métricas e o respectivo clique/ação para as Listagens de Sub-página.
- **`CatalogV2List.tsx`:** Refatorada a antiga página inteira de V2 para um sub-componente. Ela aceita parâmetros de inicialização (`initialStockLevel`, `initialHasBom`, `initialAction`) injetados diretamente por quem a aciona (Hub ou Block Clicado).
- **`BaseSubpageLayout.tsx`:** Layout compartilhado para acomodar uma visualização interna que permite "Voltar" p/ o Painel base, similar ao `BaseSubpageLayout.tsx` de Orders.
- **Router e Exportação (`pages/catalog/CatalogV2Page.tsx`):** Export path atualizado para exportar o Hub.

## Visão Geral do Fluxo
O usuário entra em Produtos (Catálogo V2), vê o dashboard modular com os blocos que contabilizam produtos atuais ou servem de atalho veloz (ex. Criar Produto -> aciona o modal autoOpen pela Listagem). Ao fechar a listagem via Header Superior (`<ArrowLeft/> Voltar`), a interface exibe o Dashboard novamente.
