# Implementação V4.28.14 - Redirecionamento Direto para Criação de BOM e Filtro em 'Gerenciar Estruturas'

## Objetivo
Melhorar a jornada de criação de rotas onde o usuário tenta criar uma Ordem de Produção de um item que ainda não possui Engenharia (Ficha Técnica). Em vez de redirecioná-lo para a tela inicial do Hub de Catálogo, ele deve ser encaminhado diretamente para a tela de "Gerenciar Estruturas", focando no respectivo produto. Além disso, a tela de "Gerenciar Estruturas" foi dividida em Abas Interativas (Com Estrutura / Sem Estrutura) para suportar também os produtos desprovidos de ficha técnica sem poluir demasiadamente a interface.

## Mudanças Realizadas
- **`CreateOrderView.tsx`:** Atualizado a prop de `navigate()` acionada pela modal de Bloqueio (sem ficha técnica). Agora injeta parâmetros de URL: `/v2/catalog?view=with-bom&expandProduct=${productId}`.
- **`useCatalogLayout.ts`:** Refatorado para ler e inicializar a navegação de sub-páginas no app de base através dos `searchParams` (`?view=`). Quando o usuário volta ao Hub da página, as props de visualização focadas no `expandProduct` são limpas da URL.
- **`CatalogV2List.tsx`:** 
  - Adicionado um estado `bomFilter` ('with', 'without', 'all') com Segmented Controls em interface (botões Com Estrutura / Sem Estrutura) caso a view seja faturada por `initialHasBom`.
  - Melhorado a inteligência de inicialização: Se o catálogo receber parâmetros na URL sinalizando uma expansão (`expandProduct`), ele adivinha qual aba (Com ou Sem Estrutura) abrir baseada no produto em faturamento ou assume "Sem Estrutura" para mitigar perdas.
- **`ProductListCard.tsx`:** Refatorado os estados de `expanded` locais para interpretarem o contexto global de inicialização `searchParams.get('expandProduct')`. Se o ID referenciado corresponder ao do Card, ele abre automaticamente e garante visibilidade imediata ao usuário.
