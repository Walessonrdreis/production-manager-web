# Implementação V4.28.7 - Confronto de Saldo na Estrutura BOM

## Objetivo
Adicionar visibilidade à quantidade em estoque real de cada insumo versus a quantidade demandada de consumo ao se verificar a estrutura de um produto (aba Estrutura BOM), auxiliando no planejamento do operador do Catálogo V2.

## Mudanças Realizadas
- **`ProductListCard.tsx`:** 
  - Consumo do hook `useOmieProducts` para recuperar a listagem completa (cacheadamente pelo React Query sem repetição de requests pesados).
  - Reestruturação das colunas no card de insumos (`grid-cols-12` flex).
  - Adição de leitura de Nomeclatura secundária do Item (caso exista no banco).
  - Adição do comparativo "Consumo vs Saldo", alinhando os valores exigidos pelo item `item.quantity` (un consumidas) contra `insumoStock` (un em estoque) utilizando indicativo de cor semântica (Verde para Saldo Positivo, Vermelho para Saldo Negativo) na própria interface do modal.
