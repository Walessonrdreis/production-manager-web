# Implementação V4.28.8 - Criação de Produto via Catálogo V2 (Workload Independente)

## Objetivo
Disponibilizar a opção do operador iniciar a criação de um novo Produto diretamente do Catálogo Unificado (V2), isolando a lógica de integração através do padrão comportamental Gateway (Strategy) com simulação ativa.

## Mudanças Realizadas
- **`CreateProductContract.ts`:** Definição da interface (porta de entrada para a criação de itens).
- **`FakeCreateProduct.ts` e `RealCreateProduct.ts`:** Estratégias do Módulo de Workloads de Criação de Produto (seguindo à risca a Regra 21).
- **`CreateProductGateway.ts`:** Implementação do Factory para gerir a variável e definir o adapter (`VITE_USE_FAKE_CREATE_PRODUCT_API`).
- **`CreateProductFormModal.tsx` & `CreateProductButton.tsx`:** UI modal interativa integrada ao Catálogo V2 para injeção de dados básicos do novo item. Atualização dos queries cacheados (`invalidateQueries`) em caso de retorno primário de sucesso.
- **Variáveis de Ambiente (`.env.example`):** Introduzido o toggle para Fake API desse Workload específico.
