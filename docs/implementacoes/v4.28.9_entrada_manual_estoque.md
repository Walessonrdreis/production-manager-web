# Implementação V4.28.9 - Entrada Manual de Estoque (Workload Independente)

## Objetivo
Disponibilizar a opção do operador inserir manualmente saldo de estoque (movimentação de entrada) para um produto específico diretamente pelos detalhes ("Comandos Rápidos") no Catálogo V2. Isso visa atender casos onde é necessário gerar Ordem de Produção urgentes mas o produto recém criado ou desprovido de Nota Fiscal ainda não possui saldo nem valor de custo no Omie. A implementação segue o design modular imposto pela Regra 21, isolando a lógica do Omie e disponibilizando um modo Fake para testes front-end.

## Mudanças Realizadas
- **`ManualStockEntryContract.ts`:** Interface (`ManualStockEntryInput`, `ManualStockEntryOutput`) contendo os requisitos de Data do Movimento, Quantidade, Valor Unitário e Observação.
- **`FakeManualStockEntry.ts` e `RealManualStockEntry.ts`:** Classes Strategy com a simulação do input manual de estoque e integração real a ser mapeada.
- **`ManualStockEntryGateway.ts`:** Gateway Factory determinando adapter em tempo de execução via `VITE_USE_FAKE_MANUAL_STOCK_API`.
- **`ManualStockEntryModal.tsx` & `ManualStockEntryButton.tsx`:** Modal UI com os campos requisitados isolada, acionada com um botão secundário integrado ao painel de detalhes expansível (`ProductListCard.tsx`) das Cargas de Trabalho.
- **Variáveis de Ambiente (`.env.example`):** Introduzido o toggle para Fake API desse Workload específico.
