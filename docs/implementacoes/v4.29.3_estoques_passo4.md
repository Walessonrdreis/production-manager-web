# Refatoração Visual e UX - Hub de Estoques

**Classificação da Mudança**: Implementação funcional / UX
**Lista de Arquivos Afetados**:
- `apps/web/src/features/stocks-v2/ui/StocksHub.tsx`

## Descrição do que foi feito

Adicionado o comportamento padrão de arrastar e reordenar aos cards do do hub principal da UI V2 de Estoques, com salvamento do estado em memória e atualização da paridade visual para match completo com a view de produtos do catálogo V2.

- **Painel de Acesso Rápido**: O Hub foi modernizado para permitir arrastar os blocos (DnD) tal como nas outras views consolidadas.
- **Identidade Coesa**: Modificamos a estrutura dos cards dentro desse Hub (cores, spacing, arredondamentos em `rounded-2xl`, etc). Inserido um rodapé demonstrativo listando quantitativos visuais simples em `border-t`, o que aumenta a utilidade da view e adere ao novo layout v2.
- **UX Geral**: Foi ajustado o padding do grid e a mensagem da header para ficar estritamente coerente com a experiência de usuários vindos do catálogo e ordens de produção.
