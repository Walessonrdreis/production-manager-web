# Versão v1.3.0 - transição para Monolito Modular

**Data:** 07/05/2026  
**Tipo:** Mudança Estrutural (Breaking Change na Organização)

## 🚀 O que há de novo?

### 🏗️ Nova Arquitetura Monorepo
- Introdução da estrutura de **Monolito Modularizado** separando o projeto em `apps/web` e `apps/api`.
- Criação do arquivo de referência centralizado `Estrutura_Monolito.md`.
- Formalização da transição através da **ADR-004**.

### 📄 Documentação e Governança
- Atualização do `PROJECT_SUMMARY.md` com os novos pilares de escalabilidade.
- Refino das instruções de agente em `AGENTS.md` para suportar tanto o desenvolvimento frontend quanto o backend futuro.
- Implementação da regra de **Contrato Primeiro (Contract-First)** para integração de dados.

## 🛠️ Detalhes Técnicos
- **Desacoplamento:** Preparação do domínio para migração de lógicas de negócio do cliente para o servidor.
- **Validação:** Reforço do uso de Zod para validação de fronteira entre as camadas `web` e `api`.
- **Persistência:** Definição da estratégia híbrida (IndexedDB + SQLite/Backend).

## 📝 Notas de Versão
Esta versão não altera funcionalidades visuais na UI, mas prepara o terreno para a implementação de um sistema multiusuário robusto e integração profunda com o ecossistema Omie via backend centralizado.
